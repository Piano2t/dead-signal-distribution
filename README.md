# DEAD SIGNAL

Jeu de survie 3D pour Windows 64 bits, en solo et en coopération jusqu’à quatre joueurs.

## Installer le jeu

Ouvrez [la dernière version](https://github.com/Piano2t/dead-signal-distribution/releases/latest), téléchargez **DeadSignal-Setup-…exe**, puis installez le jeu. Lancez **DEAD SIGNAL** depuis son raccourci. **F11** passe en plein écran et revient en fenêtre.

L’installation est disponible pour tous les utilisateurs de l’ordinateur. Windows peut demander l’autorisation d’installation.

## Jouer ensemble depuis Internet

Chaque joueur ouvre son jeu, clique sur **Coopération**, puis utilise le serveur Internet sélectionné automatiquement. Un joueur crée le salon et partage son code ; les autres saisissent ce code dans leur propre jeu. Tous les participants d’un salon doivent utiliser la même version.

Le serveur fonctionne sur l’ordinateur du créateur : cet ordinateur doit rester allumé et connecté à Internet. L’hôte de la partie garde également son jeu ouvert. Les joueurs utilisent directement leur logiciel `.exe`.

## Mises à jour

Le jeu installé recherche les mises à jour au lancement et toutes les quinze minutes. Il les télécharge automatiquement. Revenez au menu, ouvrez **Paramètres**, puis cliquez sur **Installer & relancer** lorsqu’une nouvelle version est prête.

Les anciennes éditions sans canal de mise à jour doivent installer une première fois le nouveau setup. Le fichier autonome **DeadSignal.exe** permet de jouer sans installation ; cette édition demande de remplacer manuellement son exécutable pour une nouvelle version.

Ce dépôt contient les téléchargements et l’adresse publique du serveur. Les archives « Source code » générées par GitHub contiennent seulement ces informations de distribution ; les fichiers de création du jeu sont conservés séparément.
